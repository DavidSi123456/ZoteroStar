# ZoteroStar · 期刊星级与简称

为 Zotero 10 的文献列表增加独立的「期刊星级」和「期刊简称」两列，支持排序、筛选，以及新导入文献自动评级。

## 安装

1. [下载 journal-stars-0.1.2.xpi](https://github.com/DavidSi123456/ZoteroStar/raw/refs/heads/main/dist/journal-stars-0.1.2.xpi)。
2. 打开 Zotero → 工具 → 插件，点击齿轮 →「从文件安装插件」。
3. 选择下载的 XPI。通常无需重启；如果看不到两列，可右键列表表头检查显隐设置。

目前支持 **Zotero 10.0.x**。不承诺兼容 Zotero 7、8 或 9。当前版本采用手动安装和升级。

## 使用

- **期刊星级**：独立显示 `★★★★★` 至 `★☆☆☆☆`；点击表头排序。
- **期刊简称**：优先使用内置常用简称，如 AER、QJE、JDE、JF、RFS；其次使用文献已有的简称；没有明确简称时显示原刊名。
- **分类内筛选**：工具栏的「期刊星级」菜单在当前分类中筛选，并保留其他主题标签筛选条件。
- **全库筛选**：侧栏提供五星至一星及「未评级」共六个保存搜索。
- **自动更新**：启动时匹配已有文献；新增条目或修改期刊信息后重新匹配，无需手动逐篇打分。

星级表示期刊在 AJG 2024 中的层级，不是对单篇论文质量或个人阅读价值的评价。

## 评级规则与数据来源

内置 CABS Academic Journal Guide 2024 的 1,822 本期刊目录，按刊名精确归一化匹配，忽略大小写、标点和冠词 The。

| AJG 2024 原等级 | 显示星级 |
| --- | --- |
| 4* | ★★★★★ |
| 4 | ★★★★☆ |
| 3 | ★★★☆☆ |
| 2 | ★★☆☆☆ |
| 1 | ★☆☆☆☆ |

未收录、缺少期刊名、工作论文和预印本平台不按一星处理。评级只用于 `journalArticle`；其他条目类型不显示期刊星级。

来源：[CABS AJG 2024](https://charteredabs.org/academic-journal-guide/academic-journal-guide-2024)、[北京信息科技大学公开目录](https://mse.bistu.edu.cn/xsky/qkdh/02ed507435944dd6b53aa37f065f108f.htm)。简称是界面显示约定，不作为评级依据。本项目与评级机构无隶属关系，评级数据的相关权利归原权利人。

## 文库中的变化

插件维护 `期刊星级/5`、`评级来源/AJG2024/4*` 等普通标签，创建评级保存搜索；同时迁移旧格式 `⭐⭐⭐⭐⭐ 期刊`、`期刊/未评级` 等评级标签。其他标签、分类、附件和笔记会保留。插件不修改标题、作者、原始期刊字段，也不更新条目的修改日期。

仅维护可编辑的个人文库，不写入群组和 RSS 文库。卸载插件会移除界面列和菜单，已写入的评级标签和保存搜索会保留。

匹配在本地完成，评级数据随安装包提供；插件不读取 PDF、不调用模型服务、不开放网络端口。Zotero 要求清单存在 HTTPS 更新地址，目前使用本机回环地址占位，不提供自动更新下载，也不会向外网发送文献数据。`updates.json` 是空的更新清单模板。

## 构建与测试

需要 Python 3 和支持 `node:test` 的 Node.js（建议 20 或更新版本）；无需安装 npm 或 pip 依赖。

```sh
git clone https://github.com/DavidSi123456/ZoteroStar.git
cd ZoteroStar
node --test tests/plugin.test.cjs
python3 build.py
```

构建产物：`dist/journal-stars-0.1.2.xpi`。可使用 `dist/SHA256SUMS` 校验仓库随附的安装包；重新构建时 ZIP 时间戳可能使校验值不同。

源码结构：`core.js` 负责评级、简称与标签规则；`plugin.js` 负责 Zotero 列、菜单、通知与保存搜索；`bootstrap.js` 负责插件生命周期；`rankings.json` 提供评级数据与常用简称。

离线测试覆盖全目录星级映射、常用简称、评级标签迁移、筛选条件保留、两列注册、新条目及刊名变更自动更新、群组和只读文库保护、文本安全渲染。已在 Zotero 10.0.6 完成本机安装、导入更新及原生界面验收；模拟测试不能代替所有 Zotero 版本的实际运行验证。
